# سامانه آنلاین صدور و مدیریت فاکتور (Faktor Online)

## Overview (نمای کلی پروژه)
سامانه تحت وب مدرن، کاملاً کلاینت‌ساید (بدون نیاز به سرور و دیتابیس) و ریسپانسیو برای صدور، شخصی‌سازی، پیش‌نمایش و مدیریت فاکتورهای رسمی و غیررسمی به زبان فارسی. این سامانه با رعایت کامل استانداردهای چیدمان راست‌به‌چپ (RTL)، تایپوگرافی اصیل با فونت وزیرمتن (Vazirmatn)، تقویم شمسی و تبدیل هوشمند اعداد به حروف و ارقام فارسی پیاده‌سازی شده است.

---

## Tech Stack (فناوری‌های استفاده شده)
- **Core Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 6 (با تنظیم `base: './'` سازگار با GitHub Pages)
- **Styling & Design System**: Vanilla CSS Design Tokens (Dark/Light Themes, CSS Variables, A4 Print Media Queries)
- **Icons**: Lucide React
- **PDF Export**: html2canvas + jsPDF (با مقیاس تفکیک‌پذیری بالا و رندر کامل فونت فارسی و RTL)
- **Word (.docx) Export**: docx.js + file-saver (با تنظیمات دایرکشن RTL و جدول‌های سازمان‌یافته)
- **Image Export**: html2canvas (خروجی PNG باکیفیت بالا)
- **Storage & State**: مرورگر Web Storage API (localStorage) برای ذخیره فاکتورها، وضعیت‌ها و پروفایل فروشنده
- **Deployment**: GitHub Pages با GitHub Actions

---

## Dependencies (وابستگی‌ها)
- `docx`: ساخت فایل‌های استاندارد مایکروسافت ورد با پشتیبانی از چیدمان دوطرفه و راست‌به‌چپ
- `file-saver`: ذخیره و دانلود فایل‌های ساخته‌شده در مرورگر
- `html2canvas`: تبدیل DOM پیش‌نمایش فاکتور به Canvas با وضوح بالا
- `jspdf`: تولید فایل PDF سایز A4
- `lucide-react`: آیکون‌های مدرن و هماهنگ
- `react` & `react-dom`: هسته رابط کاربری کامپوننت‌محور

## Current Features (امکانات پیاده‌سازی شده)

1. **فرم ویرایشگر فاکتور (Invoice Editor)**:
   - **بسته بودن پیش‌فرض تمام پنل‌ها در اولین بازگشایی صفحه**: همراه با کلید «باز کردن همه / بستن همه» برای تجربه کاربری خلوت و سریع
   - ثبت اطلاعات فروشنده با امکان بارگذاری لوگو (تبدیل به Base64) و ذخیره مشخصات به عنوان پیش‌فرض
   - ثبت اطلاعات کامل خریدار (شامل شناسه ملی، کد اقتصادی، تلفن، نشانی و کد پستی)
   - جدول پویای اقلام با محاسبه خودکار جمع سطر، تخفیف (درصدی یا ثابت)، مالیات ارزش افزوده و واحد کالا
   - تولید خودکار شماره فاکتور با دکمه شماره تصادفی
   - انتخاب واحد پول (تومان، ریال، دلار، یورو، درهم)
   - تاریخ صدور و سررسید شمسی با دکمه‌های میانبر (+۷ روز، +۱۴ روز) و سوییچ به تقویم میلادی
   - وضعیت‌های فاکتور: پیش‌نویس، پرداخت نشده، پرداخت شده، سررسید گذشته
   - **امکان ثبت چندین حساب بانکی مختلف**: افزودن کارت‌ها، حساب‌ها و شماره‌های شبای مجزا همراه با نام بانک و صاحب حساب با قابلیت حذف و ویرایش نامحدود
   - بارگذاری تصویر امضا و مهر اختصاصی

2. **پیش‌نمایش زنده و قالب‌های فاکتور (Templates & Live Preview)**:
   - نمایش لحظه‌ای تغییرات فرم با پشتیبانی کامل از راست‌به‌چپ (RTL)
   - ۳ قالب اختصاصی:
     - **رسمی و مالیاتی (Classic)**: مناسب شرکت‌ها و استانداردهای دارایی
     - **مدرن و سازمانی (Modern)**: کارت‌های زیبا با تفکیک رنگی
     - **مینیمال (Minimal)**: طراحی شیک بر پایه تایپوگرافی و خطوط ظریف
   - نمایش منظم تمامی حساب‌های بانکی تعریف‌شده در برگه فاکتور
   - کلیدهای تنظیم زوم و بازنشانی مقیاس پیش‌نمایش

3. **خروجی‌ها و اخطار بستن صفحه (Export Options & Unsaved Warning)**:
   - **خروجی PDF**: خروجی استاندارد A4 با کیفیت بالا و فونت فارسی
   - **خروجی Word (.docx)**: ایجاد فایل ورد با راست‌چین بودن جداول و پاراگراف‌ها شامل تمام حساب‌های بانکی
   - **خروجی تصویر**: دانلود عکس PNG شفاف و باکیفیت
   - **خروجی JSON**: دانلود کل دیتای فاکتور در قالب فایل استاندارد
   - **بازیابی از JSON (Import)**: امکان بارگذاری فایل قبلی و بازنشانی کامل فرم با اعتبارسنجی ساختار
   - **اخطار قبل از بستن صفحه (BeforeUnload Protection)**: چنانچه کاربر آخرین نسخه تغییرات را به صورت فایل JSON دانلود نکرده باشد، هنگام بستن تب یا بارگذاری مجدد، پیام اخطار مرورگر نمایش داده می‌شود.
   - **چاپ مستقیم (Print)**: با استایل‌های اختصاصی `@media print` که المان‌های پنل را پنهان کرده و فقط برگه را چاپ می‌کند

4. **مدیریت فاکتورها و پایدارسازی (Persistence & Management)**:
   - ذخیره و بارگذاری فاکتورها در حافظه مرورگر (`localStorage`)
   - جستجو بر اساس شماره، نام خریدار یا عنوان
   - فیلتر بر اساس وضعیت پرداخت
   - امکان ایجاد کپی (Duplicate) از فاکتورهای قبلی
   - امکان حذف فاکتور با پنجره تأیید
   - کلید تبدیل ارقام بین فارسی (`۱۲۳`) و انگلیسی (`123`)
   - تغییر تم روشن و تاریک (Dark / Light Mode)
   - طراحی واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ

## 🌟 درباره سامانه

**فاکتور ساز آنلاین (Persian Invoice Generator)** یک ابزار سریع، مدرن و کاملاً رایگان برای شرکت‌ها، کسب‌وکارهای آنلاین، اصناف و فریلنسرهاست. این سامانه بدون نیاز به ثبت‌نام یا ارسال اطلاعات به هیچ سروری اجرا می‌شود؛ تمام محاسبات، پردازش‌ها و ذخیره‌سازی داده‌ها **۱۰۰٪ در مرورگر کاربر (Client-Side)** انجام شده و اطلاعات مالی شما کاملاً محرمانه باقی می‌ماند.

## ✨ امکانات و قابلیت‌ها

### ۱. ویرایشگر پیشرفته و رابط کاربری
- **طراحی راست‌به‌چپ اصیل (RTL)** با تایپوگرافی چشم‌نواز و فونت **وزیرمتن (Vazirmatn)**.
- **حالت تاریک و روشن (Dark / Light Mode)** با چیدمان استاندارد و ریسپانسیو.
- **پنل‌های تاشو (Accordion)** با قابلیت باز و بسته کردن یکپارچه برای تمرکز بهتر.
- **تقویم شمسی و میلادی** همراه با میانبرهای تاریخ سررسید (+۷ روز، +۱۴ روز).
- **تبدیل هوشمند اعداد به حروف** (مانند: *۶۲,۰۰۰,۰۰۰ تومان $\to$ شصت و دو میلیون تومان*).
- **سوییچ فوری ارقام** بین اعداد فارسی (`۱۲۳`) و انگلیسی (`123`).

### ۲. محاسبات مالی، تخفیف و مالیات
- امکان درج نامحدود ردیف‌های کالا و خدمات با کلیدهای کپی و حذف سریع.
- **استپر تعداد اقلام** (`+` و `-`) با پشتیبانی از واحدهای سفارشی (عدد، پروژه، ماه، ساعت، بسته و...).
- **تخفیف پیشرفته**: به صورت درصدی (`%`) یا مبلغ ثابت.
- **روش‌های محاسبه مالیات ارزش افزوده**:
  - **یکجا روی کل فاکتور (پیش‌فرض)**: وارد کردن درصد کلی مالیات روی جمع فاکتور بدون شلوغ شدن جدول اقلام.
  - **مجزا برای هر ردیف**: امکان درج درصد مالیات اختصاصی برای هر کالا.
- امکان غیرفعال‌سازی ستون‌های تخفیف و مالیات با صفر شدن قطعی در محاسبات.

### ۳. قالب‌ها و شخصی‌سازی
- **۳ قالب استاندارد و شکیل**:
  - **رسمی (Classic)**: استاندارد دارایی و شرکت‌های تجاری.
  - **مدرن (Modern)**: کارت‌بندی شیک با تفکیک رنگی.
  - **مینیمال (Minimal)**: خلوت، سریع و مبتنی بر خطوط ظریف.
- بارگذاری لوگوی شرکت و مهر و امضای دیجیتال (ذخیره مستقیم در فرمت Base64).
- امکان پنهان‌سازی یا نمایش برچسب وضعیت (پرداخت نشده / پرداخت شده / پیش‌نویس).
- امکان پنهان‌سازی یا نمایش کادر امضای خریدار و صادرکننده.

### ۴. پشتیبانی از چندین حساب بانکی
- امکان افزودن نامحدود کارت‌های بانکی، شماره حساب و شماره شبا با تفکیک نام بانک و صاحب حساب.

### ۵. برگه پیوست و توضیحات نامحدود (چندصفحه‌ای هوشمند)
- فعال‌سازی برگه پیوست جهت درج شرایط قرارداد، فازهای فنی، ضمانت‌نامه یا تعهدات.
- **صفحه‌بندی خودکار**: توزیع هوشمند متن‌های طولانی در برگه‌های متوالی A4 (صفحه ۲ از N، ۳ از N و...) بدون برش یا تداخل کلمات.
- متن‌های آماده حقوقی و فنی برای درج سریع.

### ۶. خروجی‌های حرفه‌ای
- **خروجی PDF چندصفحه‌ای باکیفیت**: رندر مجزای هر صفحه A4 بدون افت کیفیت یا جابجایی حروف.
- **خروجی Word (.docx)**: فایل استاندارد ورد با جدول‌های کاملاً راست‌چین و سربرگ مرتب.
- **خروجی عکس (PNG)** با رزولوشن بالا.
- **پشتیبان‌گیری JSON (خروجی و بازیابی)**: ذخیره امن فاکتور در قالب فایل و امکان بارگذاری مجدد.
- **حفاظت از تغییرات ذخیره‌نشده (BeforeUnload)**: هشدار در صورت بستن ناخواسته تب قبل از دانلود JSON.

## 🚀 راهنمای استفاده گام‌به‌گام

1. وارد [majiix.github.io/Persian-Invoice-Generator](https://majiix.github.io/Persian-Invoice-Generator/) شوید.
2. در پنل **تنظیمات و مشخصات فاکتور**، عنوان فاکتور، تاریخ‌ها و واحد پول را مشخص کنید.
3. در پنل‌های **مشخصات صادرکننده** و **مشخصات خریدار**، اطلاعات تماس و لوگو را وارد نمایید.
4. در پنل **اقلام کالا و خدمات**، ردیف‌های خود را با قیمت و تعداد ثبت کنید.
5. در صورت تمایل، حساب‌های بانکی و برگه پیوست قرارداد را تکمیل نمایید.
6. در ستون پیش‌نمایش، قالب مورد نظر را انتخاب کرده و از دکمه‌های بالا خروجی **PDF**، **Word**، **تصویر** یا **چاپ** را دریافت کنید.

## 🛠️ نصب و اجرای محلی

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm** یا **yarn** یا **pnpm**

### مراحل اجرا:
```bash
# ۱. کلون کردن پروژه
git clone https://github.com/majiix/Persian-Invoice-Generator.git
cd Persian-Invoice-Generator

# ۲. نصب پکیج‌ها
npm install

# ۳. اجرای سرور توسعه محلی
npm run dev
```
برنامه در آدرس `http://localhost:5173` باز خواهد شد.

### ساخت بیلد نهایی (Production):
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist` ساخته می‌شوند.
